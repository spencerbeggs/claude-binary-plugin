# Security Policy

## Supported Versions

This project has not yet reached its initial public release. Only the
latest pre-release version receives security updates.

| Version | Supported |
| ------- | --------- |
| Latest | Yes |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.
**Do not open a public GitHub issue for security vulnerabilities.**

### How to Report

1. **Email**: Send a detailed report to
   [spencer@beggs.codes](mailto:spencer@beggs.codes)
2. **GitHub Security Advisories**: You can also report via
   [GitHub Security Advisories](https://github.com/spencerbeggs/claude-binary-plugin/security/advisories/new)

### What to Include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

### Response Timeline

- **Acknowledgment**: within 48 hours
- **Initial assessment**: within 7 days
- **Resolution target**: within 30 days for confirmed vulnerabilities

### After Reporting

You will receive an acknowledgment confirming receipt of your report. We
will work with you to understand the scope of the issue and coordinate a
fix. Credit will be given to reporters unless anonymity is requested.
