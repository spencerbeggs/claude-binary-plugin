# Hook Testing

This guide covers test patterns for all 10 hook types. Each section shows the input method, its fields, and a complete test example.

All examples use the my-plugin scaffolded project with prefix `MY_PLUGIN`, a `SessionStart/context` hook, and a `PreToolUse/security` hook.

## Base Input Fields

Every hook input extends `HookInputBase` with these optional fields. They are auto-generated by the test builder if not provided.

| Field | Type | Description |
| ----- | ---- | ----------- |
| `session_id` | `string` | Auto-generated UUID if not provided |
| `transcript_path` | `string` | Path to transcript file |
| `cwd` | `string` | Current working directory |
| `permission_mode` | `string` | `"default"`, `"plan"`, `"acceptEdits"`, or `"bypassPermissions"` |

## Permission Hooks

### PreToolUse

Runs before Claude executes a tool. Can allow, deny, modify input, or defer to the user.

**Input method:** `withPreToolUseInput(input)`

| Field | Type | Required | Description |
| ----- | ---- | -------- | ----------- |
| `tool_name` | `string` | Yes | Name of the tool being invoked |
| `tool_input` | `Record<string, unknown>` | Yes | Tool input parameters |
| `tool_use_id` | `string` | No | Auto-generated if omitted |

**Test pattern:**

```typescript
import { describe, test, expect, beforeEach, afterEach } from "bun:test";
import plugin from "../plugin.config.js";

describe("PreToolUse/security hook", () => {
  let ctx: ReturnType<typeof plugin.test>;

  beforeEach(() => {
    ctx = plugin.test()
      .withOptions({ DEBUG: "false", TIMEOUT_MS: "30000" })
      .withState({});
  });

  afterEach(() => {
    ctx.dispose();
  });

  test("allows safe commands", async () => {
    const result = await ctx
      .withPreToolUseInput({
        tool_name: "Bash",
        tool_input: { command: "git status" },
      })
      .runHook("PreToolUse", "security");

    expect(result.exitCode).toBe(0);
    expect(result.action).toBe("allow");
  });

  test("denies dangerous commands", async () => {
    const result = await ctx
      .withPreToolUseInput({
        tool_name: "Bash",
        tool_input: { command: "rm -rf /" },
      })
      .runHook("PreToolUse", "security");

    expect(result.action).toBe("deny");
    expect(result.reason).toContain("rm -rf /");
  });

  test("can modify tool input", async () => {
    const result = await ctx
      .withPreToolUseInput({
        tool_name: "Bash",
        tool_input: { command: "npm install" },
      })
      .runHook("PreToolUse", "security");

    // If the hook modifies input, check for action "modify"
    // and inspect result.output for updatedInput
  });
});
```

**Key assertions:** `result.action` is `"allow"`, `"deny"`, `"ask"`, or `"modify"`. When denying, check `result.reason`.

### PermissionRequest

Runs when Claude needs a permission decision from the user. Can auto-allow or auto-deny.

**Input method:** `withPermissionRequestInput(input)`

| Field | Type | Required |
| ----- | ---- | -------- |
| `message` | `string` | Yes |
| `notification_type` | `string` | Yes |

```typescript
test("auto-allows known permissions", async () => {
  const result = await ctx
    .withPermissionRequestInput({
      message: "Allow file read access?",
      notification_type: "permission",
    })
    .runHook("PermissionRequest", "auto-permission");

  expect(result.action).toBe("allow");
});
```

## Content Hooks

### SessionStart

Runs when Claude Code begins a new session. Primarily used for injecting context into Claude's system prompt.

**Input method:** `withSessionStartInput(input)`

| Field | Type | Required | Values |
| ----- | ---- | -------- | ------ |
| `source` | `string` | Yes | `"startup"`, `"resume"`, `"clear"`, `"compact"` |

```typescript
import { describe, test, expect, beforeEach, afterEach } from "bun:test";
import plugin from "../plugin.config.js";

describe("SessionStart/context hook", () => {
  let ctx: ReturnType<typeof plugin.test>;

  beforeEach(() => {
    ctx = plugin.test()
      .withOptions({ DEBUG: "false", TIMEOUT_MS: "30000" })
      .withState({});
  });

  afterEach(() => {
    ctx.dispose();
  });

  test("adds context on startup", async () => {
    const result = await ctx
      .withSessionStartInput({ source: "startup" })
      .runHook("SessionStart", "context");

    expect(result.exitCode).toBe(0);
    expect(result.action).toBe("context");
    expect(result.context).toContain("My Plugin Context");
  });

  test("works on resume", async () => {
    const result = await ctx
      .withSessionStartInput({ source: "resume" })
      .runHook("SessionStart", "context");

    expect(result.exitCode).toBe(0);
    expect(result.action).toBe("context");
  });
});
```

**Key assertions:** `result.action` is `"context"`. Check `result.context` for the injected text.

### PostToolUse

Runs after a tool finishes executing. Can add context or block further processing.

**Input method:** `withPostToolUseInput(input)`

| Field | Type | Required |
| ----- | ---- | -------- |
| `tool_name` | `string` | Yes |
| `tool_input` | `Record<string, unknown>` | Yes |
| `tool_response` | `Record<string, unknown>` | Yes |
| `tool_use_id` | `string` | No |

```typescript
test("adds context after tool execution", async () => {
  const result = await ctx
    .withPostToolUseInput({
      tool_name: "Bash",
      tool_input: { command: "bun test" },
      tool_response: { output: "All 42 tests passed" },
    })
    .runHook("PostToolUse", "test-reporter");

  expect(result.action).toBe("context");
  expect(result.context).toContain("tests passed");
});
```

## Control Hooks

### Stop

Runs when the agent is about to stop. Can block the stop with a reason.

**Input method:** `withStopInput(input)`

| Field | Type | Required |
| ----- | ---- | -------- |
| `stop_hook_active` | `boolean` | Yes |

```typescript
test("blocks premature stops", async () => {
  const result = await ctx
    .withStopInput({ stop_hook_active: true })
    .runHook("Stop", "guard");

  expect(result.action).toBe("block");
  expect(result.reason).toBeDefined();
});

test("allows normal stops", async () => {
  const result = await ctx
    .withStopInput({ stop_hook_active: false })
    .runHook("Stop", "guard");

  expect(result.action).toBe("continue");
});
```

### SubagentStop

Runs when a subagent is about to stop. Same interface as Stop.

**Input method:** `withSubagentStopInput(input)`

| Field | Type | Required |
| ----- | ---- | -------- |
| `stop_hook_active` | `boolean` | Yes |

```typescript
test("blocks subagent stop when work remains", async () => {
  const result = await ctx
    .withSubagentStopInput({ stop_hook_active: true })
    .runHook("SubagentStop", "subagent-guard");

  expect(result.action).toBe("block");
});
```

### UserPromptSubmit

Runs when the user submits a prompt. Can add context or block submission.

**Input method:** `withUserPromptSubmitInput(input)`

| Field | Type | Required |
| ----- | ---- | -------- |
| `prompt` | `string` | Yes |

```typescript
test("adds context for code-related prompts", async () => {
  const result = await ctx
    .withUserPromptSubmitInput({
      prompt: "Help me refactor the authentication module",
    })
    .runHook("UserPromptSubmit", "prompt-enhancer");

  expect(result.action).toBe("context");
  expect(result.context).toBeDefined();
});

test("blocks empty prompts", async () => {
  const result = await ctx
    .withUserPromptSubmitInput({ prompt: "" })
    .runHook("UserPromptSubmit", "prompt-validator");

  expect(result.action).toBe("block");
});
```

## Passthrough Hooks

Passthrough hooks observe events but cannot modify behavior. They are useful for logging, metrics, and cleanup.

### SessionEnd

Runs when a session ends.

**Input method:** `withSessionEndInput(input)`

| Field | Type | Required | Values |
| ----- | ---- | -------- | ------ |
| `reason` | `string` | Yes | `"clear"`, `"logout"`, `"prompt_input_exit"`, `"other"` |

```typescript
test("handles session end gracefully", async () => {
  const result = await ctx
    .withSessionEndInput({ reason: "logout" })
    .runHook("SessionEnd", "cleanup");

  expect(result.exitCode).toBe(0);
});
```

### PreCompact

Runs before conversation compaction.

**Input method:** `withPreCompactInput(input)`

| Field | Type | Required | Values |
| ----- | ---- | -------- | ------ |
| `trigger` | `string` | Yes | `"manual"`, `"auto"` |
| `custom_instructions` | `string` | No | Custom compaction instructions |

```typescript
test("observes compaction event", async () => {
  const result = await ctx
    .withPreCompactInput({
      trigger: "auto",
      custom_instructions: "Focus on security context",
    })
    .runHook("PreCompact", "compact-observer");

  expect(result.exitCode).toBe(0);
});
```

Runs when Claude Code sends a notification.

**Input method:** `withNotificationInput(input)`

| Field | Type | Required |
| ----- | ---- | -------- |

| `notification_type` | `string` | Yes |

```typescript
test("observes notification", async () => {
  const result = await ctx

```

## Testing Tips

- Always set up `ctx` in `beforeEach` and call `ctx.dispose()` in `afterEach` to prevent test pollution.
- Test both the happy path and edge cases (e.g., allow and deny for PreToolUse).
- For hooks that inspect `options` or `state`, vary those values across tests to verify conditional logic.
- Use `result.exitCode` to catch unexpected errors -- a value of 1 typically means the handler threw.
