# claude-binary-plugin

TypeScript SDK for building Claude Code plugins that compile to single-file Bun executables.

> **Pre-1.0 status.** This SDK is working toward its initial public release. Core functionality is implemented and stable, but the API is still being refined. Expect breaking changes before 1.0.0.

## Prerequisites

- [Bun][bun] >= 1.3.9
- [Zod][zod] >= 4.x (peer dependency)

## Reading Guide

All examples in this documentation use the scaffolded "my-plugin" project generated by `bunx claude-binary-plugin init my-plugin --yes`. The project includes a SessionStart context hook, a PreToolUse security hook, and an example command.

Start here and work through the guides in order:

1. [Getting Started][getting-started] -- scaffold, build, and run your first plugin
1. [Plugin Configuration][plugin-configuration] -- deep dive into `ClaudeBinaryPlugin.create()`
1. [Three-Layer Model][three-layer-model] -- how input, options, and state flow to handlers
1. [Hooks][hooks] -- lifecycle events, per-hook guides, tool filtering
1. [Commands][commands] -- CLI tools compiled into your plugin
1. [Testing][testing] -- fluent API, shell mocking, mock functions
1. [Type System][type-system] -- type inference, branded types, typed tool inputs
1. [Build and Distribution][build] -- compilation, proxy scripts, cross-platform
1. [State Management][state] -- PluginEnv, SessionRegistry, persistence
1. [Observability][observability] -- OTEL sidecar, telemetry classes, metrics
1. [CLI Reference][cli-ref] -- `build` and `init` command options

For badges, license information, and the quick-start snippet, see the [root README][root-readme].
